# Book Notes — Index

Index of every book processed into this vault via the book-to-obsidian-notes workflow. Each book lives in its own folder under `Claude Notes/Books/` with chapter notes, a book-level MOC, any worked examples, and follow-up guides (practical setup guide, use-case guide, quick-reference note) specific to that book.

## Books

- [[Obsidian Second Brain - MOC|Obsidian Second Brain]] — Chipak & Anderson. Obsidian-specific system: PARA, Zettelkasten, plugins, workflows.
- [[Building a Second Brain - MOC|Building a Second Brain]] — Tiago Forte. Tool-agnostic PKM methodology: CODE, PARA, Progressive Summarization. *(complete — Introduction + Chapters 1-10 + Bonus Chapter)*
- [[The PARA Method - MOC|The PARA Method]] — Tiago Forte. Full-length, standalone treatment of PARA (Projects/Areas/Resources/Archives), the classification system this book introduced inside *Building a Second Brain*. *(complete — Introduction + Chapters 1-15 + Practical Action Plan + Use Cases Guide)*
- [[System Design Interview - MOC|System Design Interview]] — Alex Xu. System design interview prep: scalability, distributed systems building blocks, and full "design X" walkthroughs. *(complete — Chapters 1-16 + Practical Study Plan + Use Cases Guide)*

## Folder convention for new books

```
Claude Notes/
  Books/
    <Book Title>/
      Chapter 1 - <Title>.md
      Chapter 2 - <Title>.md
      ...
      Conclusion - <Title>.md        (if applicable)
      <Book Title> - MOC.md
      Where Does This Go - Quick Reference.md   (if the book has a classification system)
      Examples/
      <Practical Setup Guide>.md     (if applicable)
      <Use Case Guide>.md            (if applicable)
```

Add a new line above for each book as it's completed.
